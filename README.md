Developed a fraud detection pipeline in Python using Pandas, NumPy and Scikit-learn, analysing approximately 818,000 financial transactions.

Engineered transaction-level features and addressed severe class imbalance to improve fraud classification.

Trained and compared Random Forest and XGBoost classifiers, achieving an F1-score of 95.03% on the test set at an optimised classification threshold.

Evaluated model performance using precision, recall, ROC-AUC, PR-AUC and confusion matrices.

Developed an interactive fraud monitoring dashboard featuring transaction inspection, risk indicators, performance visualisation and simulated transaction monitoring.
